# PokéBonk Offline 1.1.0

Bundled game: **PokéBonk 0.10.26 / mwsewi0r**.

- **The Great Expedition works offline:** Wild Valley and Safari Zone, local equipment and loot, extraction, inventory, Bill’s shop, contracts, and earned Expedition Pass rewards.
- **Experimental LAN co-op for 2–4 trainers:** Classic · Viridian Forest · Normal. Use the same private Wi-Fi/hotspot and matching app builds. Find a match discovers compatible open rooms; manual invitations remain available.
- Co-op uses the original room presentation, in-room Pokémon selection and local progression. Opening the Lab preserves the room; leaving and recreating rooms no longer reuses old callbacks.
- Updated homepage with Co-op beside Survival, Relay inside Game Modes, and shorter labels. Find a match is a standalone card above How to play.
- Network selection and Personal Records now use the online-style dropdown appearance, map colors, selected highlights, and animations without clipping inside panels.
- Android Automatic theme follows the device. Improved tablet Expedition outlines and entry-button borders.
- Clearer Check for updates loading/results dialogs and centered empty Personal Records messages.
- Normal earned progression and existing saves are preserved. Back up your save before upgrading. Interrupted co-op runs retain their last durable ticket/checkpoint; exact reconnection/resume and host migration are not supported.

No internet matchmaking, STUN/TURN, online leaderboards or competitive prizes are included. Some guest networks and hotspots block peer traffic or room discovery; use a private network and try a manual invitation.

Downloads: macOS Apple Silicon/Intel DMG and ZIP; Windows setup/portable EXE and ZIP; Linux AppImage/DEB; Android APK. Desktop builds are not Apple-notarized or Authenticode-signed. Android updates retain the existing application ID and signing certificate.
