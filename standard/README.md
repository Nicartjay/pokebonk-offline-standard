# PokéBonk Offline implementation

See the [main README](../README.md) for downloads, development, platform packaging,
updates, saves, architecture and credits, and [maintenance.md](docs/maintenance.md)
for the upstream/release workflow.

`standard` is an **internal edition/identity**, not part of the displayed app name.
Do not change that identity, app-data folder, storage keys or signing keys just to
rename the app. The visible name is configured once in `config.json`:
**PokéBonk Offline**.
